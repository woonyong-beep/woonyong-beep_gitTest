# DART 재무제표 파일럿 보고 (대학원생 → 연구 책임)

2026-11-13. 브랜치 `claude/buy-duration-theory-elejkp`. 이 파일의 수치는 모두 저장소의 파일과 명령으로 다시 만들 수 있다

**삼성전자 fnlttSinglAcntAll 가장 이른 연도**
- 사업보고서(11011): 2014 → 013(데이터 없음), 2015 → 있음 (CFS 184행: BS 52, IS 18, CIS 11, CF 38, SCE 65; OFS 135행). 2016 도 있음.
- 분기·반기: 2015 1분기(11013), 반기(11012), 3분기(11014) 모두 013. 2016 1분기·반기·3분기 있음. → 분기·반기는 2016 1분기부터.
- sj_div 는 다섯 가지 모두 나온다. 단일 포괄손익계산서 회사(SK하이닉스, NAVER)는 IS 가 아예 없다.

**주석**: 구조화된 주석을 주는 JSON API 는 찾지 못했다. 주석은 (a) 원문 문서(document.xml)의 표, (b) XBRL zip 에 있다.
XBRL 주석 role 은 삼성전자 FY2025 에는 있고 현대자동차 FY2022 에는 없다. 몇 년부터 있는지는 확인 안 함 (그 사이 연도 XBRL 을 받지 않았다).

**정정공시**
- 현대자동차 2022, 2021 사업보고서는 2024-03-14 에 `[기재정정]` 이 나왔다 (원래 공시 2023-03-15 20230315001030 → 정정 20240314001531).
- `fnlttSinglAcntAll` 2022·2021 은 **정정본 접수번호만** 준다 (20240314001531, 20240314001466). 원래 공시의 값을 이 API 로 받는 방법은 찾지 못했다.
- `fnlttXbrl.xml` 은 원래 공시 접수번호로도 받아진다. 현대 2022 원래 공시와 정정본의 XBRL 사실 1,126개는 값이 모두 같았다 (zip sha256 은 다름). 값이 바뀐 정정 사례는 이번 범위에서 보지 못했다.
- 공개 시점: 쓸 수 있는 날짜는 list.json 의 rcept_dt(날짜만)뿐이다. 정정본 값은 정정 접수일부터 공개된 값이다. 미래 정보 없는 백테스트라면 fnltt 값의 날짜를 정정 접수일로 잡아야 하고, 원래 공시 시점의 값은 원래 접수번호의 XBRL 이나 원문에서 받아야 한다.
- 2023~2025 의 5개사 사업보고서 15건에는 정정이 없었다 (`data/dart/extracted/filings.csv`).

**예상과 다른 것**
- `ord` 는 보이는 행 순서가 아니다. 삼성전자 FY2025 연결 BS 원문 순서와 API ord 를 견주면 52행 중 순서 뒤바뀜 313쌍 / 1,326쌍. 자산총계가 ord 7 로 유동자산(8)보다 앞에 오고, 같은 묶음 안은 대체로 account_id 알파벳 순이다 (dart_ 가 ifrs-full_ 보다 앞). 행의 부모·자식 관계는 API 에 없다. 계층과 순서는 원문 표나 XBRL presentation 링크베이스에서 가져와야 한다.
- 원문 XML 은 선언이 utf-8 인데 실제로는 EUC-KR 인 문서가 많다 (2003~2015년 문서).

`-표준계정코드 미사용-` 행은 모두 303 / 5,589 (5.4%). IS 의 "5곳 모두"가 0 인 것은 SK하이닉스·NAVER 에 IS 가 없기 때문이다.

**어색한 경우 20가지 (사실만)**
1. **ord ≠ 표시 순서, 계층 없음**: 1절. 원문 순서와 비교하면 52행 중 313쌍 뒤바뀜.
2. **같은 이름, 다른 줄**: "충당부채" 가 유동(ifrs-full_CurrentProvisions)과 비유동(NoncurrentProvisions) 둘 다에 쓰인다 (NAVER, SK, 현대). "리스부채", "기타금융자산", "기타부채", "차입금" 도 같다. 이름만으로는 구별 안 되고, API 는 위치를 주지 않는다.
3. **id 도 이름도 같은 두 줄**: 현대자동차 연결 BS "금융업채권" (`-표준계정코드 미사용-`) 55.8조 / 78.5조 (2025).
4. **같은 회사, 해마다 id 가 바뀜**: 삼성전자 미수금 `dart_ShortTermOtherReceivables`(2023) → `dart_ShortTermOtherReceivablesNet`(2024~), 선급비용 `dart_ShortTermPrepaidExpenses` → `ifrs-full_CurrentPrepaidExpenses`. 전기 비교에서 "이름바뀜/짝없음"이 많은 원인.
5. **같은 개념, 회사마다 다른 id**: 매입채무 = `ifrs-full_TradeAndOtherCurrentPayablesToTradeSuppliers`(삼성·LG·SK) / `dart_ShortTermTradePayables`(SK·현대) / `ifrs-full_TradeAndOtherPayablesToTradeSuppliers`(LG).
6. **순확정급여부채 id 3가지**: `NoncurrentRecognisedLiabilitiesDefinedBenefitPlan`(LG·NAVER·삼성), `dart_PostemploymentBenefitObligations`(현대), `RecognisedLiabilitiesDefinedBenefitPlan`(현대).
7. **같은 이름, 범위가 다른 id**: "무형자산" 이 `IntangibleAssetsAndGoodwill`(5곳)과 `IntangibleAssetsOtherThanGoodwill`(LG·삼성) 둘 다로 나온다 (영업권 포함 여부가 다른 개념).
8. **뜻 없는 이름**: LG 연결 CF "기타" = 재무활동 기타(`OtherInflowsOutflowsOfCashClassifiedAsFinancingActivities`), SK 의 "기타" = 투자활동 기타. 이름만으로는 어느 활동인지 모른다.
9. **성격별 vs 기능별 손익**: NAVER 는 영업수익/영업비용(`ifrs-full_OperatingExpense`)이고 매출원가·매출총이익·판관비가 없다. 나머지 4곳은 매출원가·매출총이익·판관비가 있다.
10. **단일 vs 두 개 포괄손익계산서**: SK하이닉스·NAVER 는 CIS 하나에 손익 항목이 다 있고 IS 가 없다. 삼성·현대·LG 는 IS + CIS 이고 CIS 에 당기순이익이 다시 나온다.
11. **영업이익은 IFRS 요소가 아님**: 5곳 모두 `dart_OperatingIncomeLoss`. 이름은 "영업이익", "영업이익(손실)".
12. **CF 부호 관례**: 유출 항목을 양수로 적는다 (유형자산의 취득, 배당금의 지급은 5곳 모두 양수, 삼성 자기주식의 취득 8.19조 양수). 소계(투자활동현금흐름 -68.5조 등)는 부호가 있다. 금액 부호만으로 유입/유출을 알 수 없다.
13. **해마다 부호가 바뀜**: 같은 줄의 전기 값이 다음 해 보고서에서 부호가 반대 (26건, 4절). 예: 삼성 SCE 배당 2023 보고서 -9,809,437백만 → 2024 보고서 전기 +9,809,437백만.
14. **OCI 법인세 부호**: LG 2024 CIS `IncomeTaxRelatingToComponentsOfOtherComprehensiveIncome...` 두 줄이 전년과 부호 반대.
15. **주당이익이 금액 표에 섞임**: 기본·희석주당이익이 IS/CIS 에 currency KRW 로 들어 있다 (삼성 6,605원, SK 62,044원). 다른 행은 원 단위 총액.
16. **같은 회사 안에서 표준/미사용 혼용**: 삼성 CF "사채 및 장기차입금의 상환" 이 해에 따라 `-표준계정코드 미사용-` 과 `RepaymentsOfNoncurrentBorrowings`, "비지배지분의 증감" 이 미사용과 `dart_DecreaseInNoncontrollingInterests`. 미사용 표시는 CF(138행)와 SCE(114행)에 몰려 있다.
17. **자본변동표는 펼쳐진 행렬**: account_detail 에 자본 구성요소 경로("자본 [구성요소]|지배기업의 소유주에게 귀속되는 지분 [구성요소]|이익잉여금 [구성요소]")와 합계 열("연결재무제표 [member]")이 들어간다. 한 줄 개념이 구성요소 수만큼 행이 된다 (SCE 2,148행 = 전체의 38%). 구성요소 집합이 회사마다 다르다.
18. **시대마다 id 접두어가 다름**: 2015 응답은 `ifrs_`(70행), 2023~ 응답은 `ifrs-full_`. xbrlTaxonomy.json 도 `ifrs_`.
19. **일반 id 아래 재분류**: NAVER CF `OtherInflowsOutflowsOfCash...` 가 2023 "현금유출입액"(순액) → 2024 "현금유입액"(총액)으로 바뀌어 id 로 짝지으면 금액다름이 된다.
20. **일부 회사에만 있는 소계·줄**: "현금및현금성자산의 증가(감소)" 가 삼성·현대는 환율효과 뒤(`IncreaseDecreaseInCashAndCashEquivalents`), LG 는 환율효과 앞(`...BeforeEffectOfExchangeRateChanges`); NAVER 는 둘 다. LG 2023 IS 에는 계속영업이익·중단영업이익 줄이 있었고 2024 에는 없다. NAVER 한 회사 안에서 "당기손익-공정가치측정금융부채" 가 id 5가지.
